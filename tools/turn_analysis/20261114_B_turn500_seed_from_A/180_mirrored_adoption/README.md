`Params/Param_B/turn_500.h`の半径2値と根拠コメントだけを変更しました。BのPID・FFと他のターンを保持しています。
変更前後は`turn_500_B_before.h` / `turn_500_B_after.h`、判断・入力ハッシュ・成果物ハッシュは`adoption.json`です。
右3本の横移動平均は90.83 mm、最大差0.79 mm、最大出口方向差0.60°です。
左の測定と連続走行の検証は今後の記録と区別します。

Debug-MouseBのConfigureとBuildが成功しました。全96コンパイルエントリーがMOUSE_Bのみであること、Aの設定が不変であること、
変更が180度の半径だけであることを確認しました。既存の未使用変数・printf書式の警告は残っています。
`cube-cmake`がPATHにないため、導入済みSTM32バンドルのCMake・Ninja・Arm GCCで同じpresetを実行しました。
コンパイラとコマンドは`adoption.json`、ビルド出力は`build_Debug_MouseB.log`に保存しています。
