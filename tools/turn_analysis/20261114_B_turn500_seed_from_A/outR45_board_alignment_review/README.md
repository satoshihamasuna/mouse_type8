# 右45度出口の評価基準についての補足（2026-11-15）

ユーザーから「動画ではもっとずれて見える」と指摘があり、盤面固定で再確認しました。固定開始点(90,45) mm・停止目標(225,315) mmに対し、床平面へ投影したマーカー中点の停止位置は左へ約2.8–9.3 mm、下へ約0.9–3.7 mmずれています。入口方向は45°に対して約0.41–1.75°、出口方向は90°に対して約0.66–1.89°の差がありました。生の盤面座標の直線当てはめでも確認しました。機軸や高さ補正済みの絶対位置とは区別しています。

既存の相対評価は入口の実測進行方向に軸を合わせるため、入口方向のずれを差し引いたターン形状の結果です。相対的な終点差や出口差が小さいことを、盤面固定のずれも解消したと説明したのは不適切でした。元の3本の数値は変更せず、評価範囲を訂正します。

説明後、ユーザーは「盤面だけで判断すると大変なことになるからそれでいいや」と、相対基準での形状評価を維持する方針を指定しました。32.8/18.0 mm・半径−50 mm・補正＋0.5°・Bの旋回P0.10は相対基準の単体候補として維持し、盤面固定・連続接続が合格したとは扱いません。ターン設定へ設置誤差を一律に埋め込まず、目的に応じて両基準を区別します。追加の実走・ファームの有効値変更・書込みは行っていません。機体B/HY0020は両方OFF確認済み、接続終了です。
