# 機体B・右135度入口・撮影4回目の除外と撮影条件の確認

半径−32.3/Lstart44.0/Lend38.35 mm・補正＋0.5°・旋回P0.10、その他のB PID/FF・500プリセットは同一。走行1回・再送0回、停止・動画/CSV/設定保存、両方OFF、接続サービス終了を確認済み。
必要区間の全フレーム観測は278/296＝93.9189%で95%条件未達。盤面校正100%、ログ欠落/CRC異常0、最低7.6602 V。静止固定窓も279/288＝96.875%で99%条件未達。静止RMS0.2381 mm/最大0.5747 mm、開始中点差0.6680 mm/向き差0.3106°は範囲内。両方の認識不足を根拠に再現性の集計から除外する。有効記録は撮影1回目と3回目の2本のまま。
欠測18フレームの原画像3枚と切り出しを保持。赤openingなしの診断で9枚は組を作れたが残りは不可、黄色opening有無で改善なし。診断結果を正式な軌跡へ流用しない。色・間隔・観測率の判定基準は変更していない。

準備処理の連続実行により、準備確認記録から走行指令まで前回122.673秒→今回80.976秒（41.697秒短縮）。接続から静止検査終了まで45.922秒。物理的な電源ON時刻を直接測った値ではない。詳細は../fast_preparation_timing_comparison.json。

ユーザーはマーカー変更・追加照明が難しいため撮影条件での対応を希望。機体OFFでPixelライトOFF/ON各3秒を試したが、露光約4.117 ms・ISO112がほぼ同一。露出−12/−18段の各3秒も露光は4.117 msのままで格子校正が不足したため不採用。カメラ設定は−6段・ライトOFF・AF固定へ戻した。撮影条件の比較は走行0回、認識改善の実走検証ではない。
カメラ側ズーム対応は別コピーで準備し、既存環境・既存測定資料を保持する。改修・静止検証を済ませるまで次の走行を行わない。Params有効値・書込みなし。
