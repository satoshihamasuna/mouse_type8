# 右135度出口の開始配置の訂正と記録

ユーザーから開始位置が穴に干渉するとの指摘を受け、(135,45) mmへの指定を撤回しました。名目中心/マーカー軌道が盤内でも、タイヤや接地点と穴が干渉しない根拠にはなりません。今回の135/45 mmからの斜め前走は(180,90) mmの黒い穴の位置に近接します。旧メタデータは再開不可として保持し、静止2回・モータ走行0回の資料も保持しています。

過去のA右135出口には穴で却下した配置の記録と、穴を避けた後に同じ候補3本を走らせ、操作者が穴/壁への接触なしを確認した記録がありました。採用した当時の盤面位置は概ね(180,135) mm・右下45°。古いpose座標は左右が反転しているため、保存AR基準から現在の盤面左上原点/右X/下Yへ変換しました。機体・色・AR識別子・カメラ高さが違うため、Bの無条件採用根拠にはしません。

新しいOFF静止撮影ではBが約(179,42) mm・前黄が右下約46°に移ったことを確認。現位置を基準(180,45) mmとして準備しました。Aの穴回避実績配置より上に90 mm、Bの右45出口の使用済み配置より右に90 mmの配置で、90 mm間隔の黒点に対する位相は同じです。ただし穴位置モデルは全穴/接地点の実測ではなく、Bの全接地点・車幅・旋回/停止余裕は操作者の現物確認を必要とします。現在は全てOFF確認済み、BLE接続終了、B右135出口の走行は0回です。

スキルのreferences/start-placements.mdに、使用済み/未確認/却下の位置と向き、機体、注意、根拠リンクを記録。SKILL.mdとturn500-workflow.mdから必ず参照するよう追記しました。写真リンクをユーザー向け本文に明示すること、位置合わせ失敗が続いたらOFFカメラだけで合わせることも記録。quick_validateとローカル参照リンク確認を通過しています。
