# 赤・黄マーカー動画と走行ログの比較

- 対象: `trim.mp4` / `20260725_004549_myshell_debug_log_long_r90.csv`
- 赤・黄マーカー検出率: 98.7 %
- 4個のArUco同時検出率: 92.8 %
- マーカー間隔: 54.71 ± 0.57 mm
- 推定スローモーション倍率: 8.600 倍
- 動画とログの軌跡RMSE: 6.52 mm（中央値 6.64 mm）
- ターン区間RMSE: 7.68 mm
- 走行中の速度RMSE: 118.7 mm/s（相関 0.9855）
- 中央ターン半径: 動画 55.89 mm / ログ 49.64 mm（差 +6.24 mm）
- LED点灯区間: 2.308～2.777 s（動画時間）
- 動画のLED端→円弧接点（幾何推定）: 前 14.60 mm / 後 -0.13 mm
- ログのlengthリセット区間（`ego.length`）: 前 3.40 mm / 後 179.75 mm
- 同区間の`ideal.length`: 前 3.98 mm / 後 184.88 mm
- 画像実軌跡（滑り込み）を角速度プロファイルへ合わせた必要値: `Lstart` 14.67 mm / `Lend` 36.23 mm
- 動画マーカー方位変化: -89.63 deg
- ログ積分方位変化: -90.05 deg

緑線は動画から得た赤・黄マーカーの中点、赤線はログの `ego.velo` と
`ego.rad_velo` を積分し、時間・剛体位置合わせした軌跡です。位置合わせで
距離尺度は変更していません。

動画の幾何推定値は、LED点灯開始位置から円弧入口接線点まで、および円弧
出口接線点からLED消灯位置までを進行方向へ射影した値です。ログ値は
`ideal.length` のリセットから角速度立ち上がりまで、および角速度終了後の
次のlengthリセットまでにおける `ego.length` の最大値です。定義が異なる
ため、両者を分けて表示しています。

滑り込み画像値は、`ideal.rad_velo` の主プロファイル開始・終了を動画時刻へ
写し、その間のマーカー実変位をターン本体としたとき、90 x 90 mmの目標
変位を満たす前後直線長を解いた値です。
