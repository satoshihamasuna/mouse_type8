# 赤・黄マーカー動画と走行ログの比較

- 対象: `trim.mp4` / `20260725_005405_myshell_debug_log_long_l180.csv`
- 赤・黄マーカー検出率: 99.4 %
- 4個のArUco同時検出率: 100.0 %
- マーカー間隔: 54.50 ± 0.80 mm
- 推定スローモーション倍率: 7.475 倍
- 動画とログの軌跡RMSE: 9.35 mm（中央値 5.74 mm）
- ターン区間RMSE: 12.05 mm
- 走行中の速度RMSE: 314.0 mm/s（相関 0.9730）
- 中央ターン半径: 動画 45.22 mm / ログ 48.15 mm（差 -2.93 mm）
- LED点灯区間: 1.682～2.591 s（動画時間）
- 動画のLED端→円弧接点（幾何推定）: 前 39.71 mm / 後 13.39 mm
- ログのlengthリセット区間（`ego.length`）: 前 3.82 mm / 後 90.00 mm
- 同区間の`ideal.length`: 前 3.98 mm / 後 88.69 mm
- 90 x 90 mm変位を仮定する滑り込みLstart/Lend推定: `long_l180` には非適用
- 動画マーカー方位変化: 180.19 deg
- ログ積分方位変化: 179.47 deg

緑線は動画から得た赤・黄マーカーの中点、赤線はログの `ego.velo` と
`ego.rad_velo` を積分し、時間・剛体位置合わせした軌跡です。位置合わせで
距離尺度は変更していません。

動画の幾何推定値は、LED点灯開始位置から円弧入口接線点まで、および円弧
出口接線点からLED消灯位置までを進行方向へ射影した値です。ログ値は
`ideal.length` のリセットから角速度立ち上がりまで、および角速度終了後の
次のlengthリセットまでにおける `ego.length` の最大値です。定義が異なる
ため、両者を分けて表示しています。

滑り込み画像値は、`ideal.rad_velo` の主プロファイル開始・終了を動画時刻へ
写し、その間のマーカー実変位をターン本体としたとき、90 x 90 mmの目標
変位を満たす前後直線長を解いた値です。
