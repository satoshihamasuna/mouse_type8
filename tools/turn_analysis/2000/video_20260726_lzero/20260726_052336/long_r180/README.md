# 赤・黄マーカー動画と走行ログの比較

- 対象: `trim.mp4` / `20260726_052336_myshell_debug_log_long_r180.csv`
- 赤・黄マーカー検出率: 96.8 %
- 4個のArUco同時検出率: 100.0 %
- マーカー間隔: 54.60 ± 1.09 mm
- 推定スローモーション倍率: 8.000 倍
- 動画とログの軌跡RMSE: 10.08 mm（中央値 8.27 mm）
- ターン区間RMSE: 11.02 mm
- 走行中の速度RMSE: 271.8 mm/s（相関 0.9766）
- 中央ターン半径: 動画 42.85 mm / ログ 46.07 mm（差 -3.22 mm）
- LED点灯区間: 1.672～2.574 s（動画時間）
- 動画のLED端→円弧接点（幾何推定）: 前 45.50 mm / 後 6.20 mm
- ログのlengthリセット区間（`ego.length`）: 前 3.96 mm / 後 89.69 mm
- 同区間の`ideal.length`: 前 3.98 mm / 後 90.38 mm
- 90 x 90 mm変位を仮定する滑り込みLstart/Lend推定: `long_r180` には非適用
- 動画マーカー方位変化: -183.92 deg
- ログ積分方位変化: -182.87 deg

緑線は動画から得た赤・黄マーカーの中点、赤線はログの `ego.velo` と
`ego.rad_velo` を積分し、時間・剛体位置合わせした軌跡です。位置合わせで
距離尺度は変更していません。

動画の幾何推定値は、LED点灯開始位置から円弧入口接線点まで、および円弧
出口接線点からLED消灯位置までを進行方向へ射影した値です。ログ値は
`ideal.length` のリセットから角速度立ち上がりまで、および角速度終了後の
次のlengthリセットまでにおける `ego.length` の最大値です。定義が異なる
ため、両者を分けて表示しています。

滑り込み画像値は、`ideal.rad_velo` の主プロファイル開始・終了を動画時刻へ
写し、その間のマーカー実変位をターン本体としたとき、90 x 90 mmの目標
変位を満たす前後直線長を解いた値です。
