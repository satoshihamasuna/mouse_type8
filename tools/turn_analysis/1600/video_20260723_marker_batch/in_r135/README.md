# 青・黄マーカー動画と走行ログの比較

- 対象: `trim_in_r135.mp4` / `20260723_230706_myshell_debug_log_in_r135.csv`
- 青・黄マーカー検出率: 90.6 %
- 4個のArUco同時検出率: 95.3 %
- マーカー間隔: 51.20 ± 7.60 mm
- 推定スローモーション倍率: 8.225 倍
- 動画とログの軌跡RMSE: 5.38 mm（中央値 5.66 mm）
- ターン区間RMSE: 4.88 mm
- 走行中の速度RMSE: 111.1 mm/s（相関 0.9798）
- 中央ターン半径: 動画 37.37 mm / ログ 39.99 mm（差 -2.62 mm）
- LED点灯区間: 1.958～2.734 s（動画時間）
- 動画のLED端→円弧接点（幾何推定）: 前 40.58 mm / 後 9.01 mm
- ログのlengthリセット区間（`ego.length`）: 前 13.84 mm / 後 24.42 mm
- 同区間の`ideal.length`: 前 14.23 mm / 後 28.80 mm
- 90 x 90 mm変位を仮定する滑り込みLstart/Lend推定: `in_r135` には非適用
- 動画マーカー方位変化: -136.96 deg
- ログ積分方位変化: -135.64 deg

緑線は動画から得た青・黄マーカーの中点、赤線はログの `ego.velo` と
`ego.rad_velo` を積分し、時間・剛体位置合わせした軌跡です。位置合わせで
距離尺度は変更していません。

動画の幾何推定値は、LED点灯開始位置から円弧入口接線点まで、および円弧
出口接線点からLED消灯位置までを進行方向へ射影した値です。ログ値は
`ideal.length` のリセットから角速度立ち上がりまで、および角速度終了後の
次のlengthリセットまでにおける `ego.length` の最大値です。定義が異なる
ため、両者を分けて表示しています。

滑り込み画像値は、`ideal.rad_velo` の主プロファイル開始・終了を動画時刻へ
写し、その間のマーカー実変位をターン本体としたとき、90 x 90 mmの目標
変位を満たす前後直線長を解いた値です。
