# long_r180 video retest

追加された2動画を対応ログと照合し、マウスの移動開始1秒前から停止1秒後まで
一時切り抜きして解析した。比較のため直前の同設定走行も併記する。3走行の
設定値はすべて同一である。

| run | 軌跡RMSE [mm] | ターンRMSE [mm] | 方位 動画/ログ [deg] | 動画−ログ [deg] | 半径 動画/ログ [mm] | log実測 Lstart/Lend [mm] |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| previous | 7.22 | 8.05 | -180.88 / -180.45 | -0.43 | 44.82 / 46.78 | 9.45 / 28.53 |
| new 1 | 4.86 | 5.21 | -181.06 / -180.44 | -0.62 | 47.52 / 46.77 | 10.00 / 28.53 |
| new 2 | 7.13 | 9.61 | -182.01 / -180.81 | -1.19 | 45.90 / 46.59 | 9.86 / 29.91 |
| mean | 6.40 | 7.62 | -181.32 / -180.57 | -0.75 | 46.08 / 46.71 | 9.77 / 28.99 |

## 所見

- 新規1本目は3走行中でもっとも良く、軌跡RMSEは4.86 mmである。
- 新規2本目は旋回量が動画で-182.01 degとなり、ログより1.19 deg多い。
- 3走行平均でも動画はログより0.75 deg多く旋回しており、わずかな過旋回傾向が再現した。
- 動画の実効半径は46.08 ± 1.36 mm、ログは46.71 ± 0.11 mmで、平均半径は0.63 mm小さい。
- ログ実測距離はLstart 9.77 ± 0.29 mm、Lend 28.99 ± 0.79 mmで比較的安定している。

各`run_*`ディレクトリに切り抜き境界、フレーム別姿勢、ログ比較、凡例付き
軌跡画像、比較グラフ、および全指標を保存している。一時切り抜きMP4は解析後
に削除している。
