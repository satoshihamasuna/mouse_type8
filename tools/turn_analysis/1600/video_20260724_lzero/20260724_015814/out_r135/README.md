# 赤・黄マーカー動画と走行ログの比較

- 対象: `trim.mp4` / `20260724_015814_myshell_debug_log_out_r135.csv`
- 赤・黄マーカー検出率: 99.3 %
- 4個のArUco同時検出率: 99.3 %
- マーカー間隔: 54.32 ± 0.85 mm
- 推定スローモーション倍率: 8.300 倍
- 動画とログの軌跡RMSE: 6.80 mm（中央値 6.67 mm）
- ターン区間RMSE: 6.44 mm
- 走行中の速度RMSE: 69.3 mm/s（相関 0.9929）
- 中央ターン半径: 動画 38.20 mm / ログ 39.16 mm（差 -0.95 mm）
- LED点灯区間: 2.200～2.900 s（動画時間）
- 動画のLED端→円弧接点（幾何推定）: 前 26.79 mm / 後 8.91 mm
- ログのlengthリセット区間（`ego.length`）: 前 1.65 mm / 後 89.44 mm
- 同区間の`ideal.length`: 前 3.20 mm / 後 89.31 mm
- 90 x 90 mm変位を仮定する滑り込みLstart/Lend推定: `out_r135` には非適用
- 動画マーカー方位変化: -135.01 deg
- ログ積分方位変化: -135.39 deg

緑線は動画から得た赤・黄マーカーの中点、赤線はログの `ego.velo` と
`ego.rad_velo` を積分し、時間・剛体位置合わせした軌跡です。位置合わせで
距離尺度は変更していません。

動画の幾何推定値は、LED点灯開始位置から円弧入口接線点まで、および円弧
出口接線点からLED消灯位置までを進行方向へ射影した値です。ログ値は
`ideal.length` のリセットから角速度立ち上がりまで、および角速度終了後の
次のlengthリセットまでにおける `ego.length` の最大値です。定義が異なる
ため、両者を分けて表示しています。

滑り込み画像値は、`ideal.rad_velo` の主プロファイル開始・終了を動画時刻へ
写し、その間のマーカー実変位をターン本体としたとき、90 x 90 mmの目標
変位を満たす前後直線長を解いた値です。
