# in_r135 前方マーカ色の比較

| 項目 | 青（前回） | 赤（今回） |
|---|---:|---:|
| マーカ検出率 | 90.6 % | 98.0 % |
| マーカ間隔の標準偏差 | 7.60 mm | 1.19 mm |
| ターン区間の軌道RMSE | 4.88 mm | 4.75 mm |
| 動画の旋回角 | -136.96 deg | -136.49 deg |
| ログの旋回角 | -135.64 deg | -135.73 deg |
| 旋回角の絶対誤差 | 1.31 deg | 0.76 deg |

赤マーカでは青色LEDとの色競合がなく、検出率が7.4ポイント向上した。
また、前後マーカ間隔の標準偏差が84 %減少しており、青色LEDを前方マーカとして
誤認したことによる軌道のジグザグは解消したと判断できる。
