# 2026-07-26 long180 ピンク線区間基準

動画のターンLED点灯区間、すなわち`trajectory_overlay.jpg`のピンク線の
先頭から末尾までを旋回本体として計算した。ログ同期した角速度区間の位置は
境界として使用していない。初期方向は動画冒頭20フレームのマーカー姿勢、
終了方向はログの実旋回角を使用した。

180度ターンのため、ピンク軌跡の前進方向頂点が95 mmになるように
`Lstart`を決め、目標終点`(-90, 0)`への残りから`Lend`を求めた。
品質判定は8倍固定の動画―ログ解析と同じ採否を引き継いだ。
