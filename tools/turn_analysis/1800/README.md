## 調整根拠

### in45

jerkを中間値へ上げたログでは電圧飽和0%を維持しながら前後半RMSが改善しましたが、
右-1.574°、左-0.414°の角度不足と、ターン後の負方向残留が残りました。加速側を
増やすとピーク電圧を増やすため、減速項を右0.00082、左0.00084へ下げ、終端の
制動量だけを減らします。

### in135

前半平均誤差は右-1.208 rad/s、左-0.680 rad/s、後半平均誤差は右+0.912 rad/s、
左+0.431 rad/sでした。飽和がないため加速・減速項をともに増やし、角度総量を
大きく変えずに位相追従を改善します。ターン後に正方向残留があるため、減速側を
加速側よりわずかに強くしています。

### V90

低jerk設定では飽和率は下がりましたが、角度誤差が右+1.206°、左+1.561°へ変化し、
後半オーバーも増えました。過去の高jerk設定と今回設定の中間で角度誤差がほぼ0に
なるよう、左右とも2.8×10^-6を採用します。推定角速度FFピークは右5.40 V、
左5.57 V、jerk制限到達率は左右とも10%です。

### long180

前半追従は良好ですが、右+1.089°、左+0.206°の角度過大と、後半・ターン後の
正方向残留があります。加速側は維持し、減速項だけを右0.00090、左0.00087へ
増やします。

## 区間抽出

ログに指定ターン以外の旋回が含まれる場合があります。解析ではSettingsの方向と、
速度・`r_min`・旋回角から求めたプロファイル時間を照合し、目的区間だけを使用します。

## 再解析方法

```powershell
python tools/analysis/turn_ff_report.py --speed 1800 --motion long_r90 long_l90 in_r45 in_l45 in_r135 in_l135 r_v90 l_v90 long_r180 long_l180 --project-header Params/Param_A/turn_1800.h
```

今回の変更値は新ログでは未検証です。同じPIDと吸引条件で再走行し、変更前後の
前後半RMS、角度誤差、ターン後残留、電圧飽和率を比較してください。
