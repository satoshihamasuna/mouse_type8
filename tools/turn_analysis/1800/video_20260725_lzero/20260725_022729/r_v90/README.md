# 赤・黄マーカー動画と走行ログの比較

- 対象: `trim.mp4` / `20260725_022729_myshell_debug_log_r_v90.csv`
- 赤・黄マーカー検出率: 98.4 %
- 4個のArUco同時検出率: 18.8 %
- マーカー間隔: 54.20 ± 0.67 mm
- 推定スローモーション倍率: 8.750 倍
- 動画とログの軌跡RMSE: 6.85 mm（中央値 5.24 mm）
- ターン区間RMSE: 9.86 mm
- 走行中の速度RMSE: 166.5 mm/s（相関 0.9662）
- 中央ターン半径: 動画 44.85 mm / ログ 42.51 mm（差 +2.35 mm）
- LED点灯区間: 2.042～2.444 s（動画時間）
- 動画のLED端→円弧接点（幾何推定）: 前 22.46 mm / 後 -12.19 mm
- ログのlengthリセット区間（`ego.length`）: 前 1.65 mm / 後 62.69 mm
- 同区間の`ideal.length`: 前 3.59 mm / 後 83.19 mm
- 90 x 90 mm変位を仮定する滑り込みLstart/Lend推定: `r_v90` には非適用
- 動画マーカー方位変化: -92.02 deg
- ログ積分方位変化: -94.02 deg

緑線は動画から得た赤・黄マーカーの中点、赤線はログの `ego.velo` と
`ego.rad_velo` を積分し、時間・剛体位置合わせした軌跡です。位置合わせで
距離尺度は変更していません。

動画の幾何推定値は、LED点灯開始位置から円弧入口接線点まで、および円弧
出口接線点からLED消灯位置までを進行方向へ射影した値です。ログ値は
`ideal.length` のリセットから角速度立ち上がりまで、および角速度終了後の
次のlengthリセットまでにおける `ego.length` の最大値です。定義が異なる
ため、両者を分けて表示しています。

滑り込み画像値は、`ideal.rad_velo` の主プロファイル開始・終了を動画時刻へ
写し、その間のマーカー実変位をターン本体としたとき、90 x 90 mmの目標
変位を満たす前後直線長を解いた値です。
