- 4個のArUco同時検出率: 100.0 %
- マーカー間隔: 55.10 ± 0.99 mm
- 推定スローモーション倍率: 4.000 倍
- 動画とログの軌跡RMSE: 3.72 mm（中央値 2.95 mm）
- ターン区間RMSE: 5.85 mm
- 走行中の速度RMSE: 78.4 mm/s（相関 0.9908）
- 中央ターン半径: 動画 38.59 mm / ログ 45.68 mm（差 -7.09 mm）

- 90 x 90 mm変位を仮定する滑り込みLstart/Lend推定: `in_r135` には非適用

- ログ積分方位変化: -135.51 deg

緑線は動画から得た赤・黄マーカーの中点、赤線はログの `ego.velo` と
`ego.rad_velo` を積分し、時間・剛体位置合わせした軌跡です。位置合わせで
距離尺度は変更していません。

動画の幾何推定値は、LED点灯開始位置から円弧入口接線点まで、および円弧
出口接線点からLED消灯位置までを進行方向へ射影した値です。ログ値は
`ideal.length` のリセットから角速度立ち上がりまで、および角速度終了後の
次のlengthリセットまでにおける `ego.length` の最大値です。定義が異なる
ため、両者を分けて表示しています。

滑り込み画像値は、`ideal.rad_velo` の主プロファイル開始・終了を動画時刻へ
写し、その間のマーカー実変位をターン本体としたとき、90 x 90 mmの目標
変位を満たす前後直線長を解いた値です。
