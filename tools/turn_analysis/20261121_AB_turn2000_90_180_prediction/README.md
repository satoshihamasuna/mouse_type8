# 機体A・機体B turn_2000（90°・180°）走行データからの予測とパラメータ更新（2026-11-21）

保存済みの実機走行データ（カメラ相対中点評価・1 ms保存ログ・2000 mm/s過去動画および角速度追従ログ）から、**機体A**（`Params/Param_A/turn_2000/`）および**機体B**（`Params/Param_B/turn_2000/`）の **90°ターン（`long_r90` / `long_l90`）** と **180°ターン（`long_r180` / `long_l180`）** のパラメータを予測・同定し、ソースのターン表（機体Bは角速度Iゲインを含む）を更新した。

本更新は保存済みデータから導出した**暫定採用値**であり、今回の更新後に実機へのファームウェア書き込みや追加走行は行っていない。

### 2.4 機体B `turn_2000` 180°（機体B 1600 R180実測＋機体B 2000 R90実測動特性＋180°運動学モデル）

入力データ：`tools/logs/pixel_camera/turn1600_B_r180_20261120_v1`（反復3本：`r_min = -47.5 mm, Lstart = 13.12 mm, Lend = 27.38 mm, corr = +0.5°`）および `turn2000_B_r90_20261120_v1`（5本：`om_ki = 0.005`）。

1. **角速度Iゲイン `om_gain_turn180_2000.Ki` (`0.01f → 0.005f`)**
   - 機体Bの2000 R90実測で確認された角速度I項のワインドアップ抑制（`Ki = 0.005f`）を、旋回時間が約2倍（約112 ms）長い2000 180°ターンにも同様に適用した。

2. **最小曲率半径 `r_min` (`±47.0f → ±50.0f`)**
   - 変更前の `turn_2000.cpp` では `r_min = ±47.0f` と、機体Bの **1600 mm/s 採用値（`±47.5f`）よりも小さい値** が残っていた。
   - 機体Bはターン専用の並進速度FF（`ff_sp_turn_velo_sq`）を使用していないため、1600 R180 旋回中の車輪平均速度比 $v_{\text{enc}}/v_{\text{ideal}} = 0.967$（機体Aは $0.991$）となり、1600 mm/s で返り幅 $90\text{ mm}$ を得るために $|r_{\min}| = 47.04\text{ mm}$（採用 `47.5 mm` で実測幅 `91.06 mm`、理想クロソイド幅 $100.76\text{ mm}$ に対する有効幅比 $w_{\text{ratio}} = 0.9037$）を要した。
   - 機体Bの 1600 → 2000 R90 実測では旋回中の $v_{\text{enc}}/v_{\text{ideal}}$ が $0.992 \to 0.973$（$-1.92\%$）低下しており、112 ms 持続する 180°旋回での速度低下と横滑りによる有効幅比の低下（$w_{\text{ratio}}: 0.9037 \to 0.854$、$-5.5\%$）を補償するには、理想幅 $90.0 / 0.854 = 105.4\text{ mm}$ に対応する **`|r_min| = 50.0 mm`**（理想幅 $106.06\text{ mm}$、予測実測幅 $90.57\text{ mm}$）が必要となる。

3. **`Lstart = 4.46f`・`Lend = 35.12f`・`degree_correction = ±0.5f`**
   - **`Lstart = 4.46f`**：機体B 1600 R180（`r = -47.5 mm, Ls = 13.12 mm`）の実測頂点は平均 `186.14 mm`（目標 `185.0 mm` に対し $+1.14\text{ mm}$、理想頂点 $183.04\text{ mm}$ に対する前方滑り・遅れ量 `apex_diff = +3.10 mm`）であった。2000 mm/s・`r = -50.0 mm` では理想曲線頂点深さ $\max F$ が $79.92 \to 84.44\text{ mm}$（$+4.52\text{ mm}$）増加し、さらに機体Bの 1600 → 2000 R90 実測における旋回前進変位 `eff_dF` の増加量（$+3.00\text{ mm}$）が加わるため、頂点 $185.0\text{ mm}$ を満たす `Lstart` は $95.0 - 84.44 - (3.10 + 3.00) = \mathbf{4.46\text{ mm}}$ となる。
   - **`Lend = 35.12f`**：1600 mm/s において機体B（`Lend = 27.38 mm` → 実測 `Lend` 前 `92.27 mm`）と機体A（`Lend = 27.38 mm` → 実測 `Lend` 前 `92.75 mm`）の旋回終了位置は $0.48\text{ mm}$ 差で一致している。機体Bの 1600 → 2000 での `Lstart` 減少量（$-8.66\text{ mm}$）、理想終点 $\Delta F$ 増分（$+0.90\text{ mm}$）、および 1600 → 2000 での旋回後半の前方遅れ増分（$+13.2\text{ mm}$）を合算すると、目標 `Lend` 前 $= 90.0\text{ mm}$ に対する予測値は **`35.12 mm`**（機体Aの `35.62 mm` との差 $-0.50\text{ mm}$ は 1600 実測での両機体差 $-0.48\text{ mm}$ と整合）となる。
   - **`degree_correction = ±0.5f`**：機体Bは `om_ki = 0.005f` 適用後の 2000 R90 実測で 1600 R90 と同じ角度補正（$+1.0^\circ$）に収束したため、180°ターンも機体B 1600 R180 反復3本（平均 `179.78°`）で検証済みの右 **`+0.5f`**・左 **`-0.5f`** を維持した。

## 4. 未確認事項・制限

- **機体B 右90°（2000 mm/s）** は実測5試行から同定した値であるが、更新後の `(Lstart, Lend, corr) = (10.22, 42.78, +1.0)` での再試走確認は未実施。
- **機体A 右90°・右180°（2000 mm/s）** および **機体B 右180°（2000 mm/s）** は 1600 / 1800 mm/s（吸引duty 650）実測と 2000 mm/s 過去データ・運動学モデルからの予測値であり、吸引duty 650・2000 mm/s での単体カメラ検証は未実施。
- **左旋回（`L90` / `L180`）** はすべて右旋回の鏡映し（`r_min`・`degree`・`degree_correction` の符号反転）であり、左単体走行および迷路での連続走行接続は未検証。
