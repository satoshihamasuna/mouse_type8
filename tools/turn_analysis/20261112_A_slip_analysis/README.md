# 機体A turn500：保存済み動画・ジャイロ・横加速度による滑りの再評価

2026-11-12。最新の14種類×3本＝42試行を再解析した。
**目印中点の移動方向が機体の向きに遅れる挙動は見えるが、その全量をタイヤの横滑りとは確定できない。**
動画とログの同期方法、および目印中点と車軸の前後位置差が大きく効く。
機体・カメラへの接続、追加走行、ファームウェアやParamsの変更は行っていない。

**既存LEDについての追記：**
[点灯開始とログのターン入口の照合](../20261112_A_led_sync_review/README.md)を42本で行い、
既存の青色LEDが同期基準に使えることを確認した。
本解析はそのLED基準を使用しておらず、軌跡同期に対する姿勢同期の差を示したもの。
既存LEDを調べる前に新しい点滅機能を優先する必要はない。
LED基準による暫定補正は中央値+7.05 msで、直接GPIO時刻がないため数msの幅が残る。

   これは位置の実測値ではなく、データに当てはめた競合仮説。

## 動画とジャイロの比較

動画の実PTSに対して局所3次多項式を当て、位置の1階・2階微分から速度と加速度を求めた。
主設定の微分窓は前後25 ms、感度確認は前後15／35 ms。
未検出は有効な観測として採用せず、20 msを超える観測欠測をまたぐ窓は使わない。
これは数十ms規模を平滑化した評価であり、1 ms以下の時定数を測定できるものではない。

実測`ego.rad_velo`は静止時バイアスを引き、実時刻で連続積分した。
途中でリセットされる`ego.radian`や、モデル計算値`ego.turn_slip_theta`を真値に使っていない。
前後の直進で横滑りが0と仮定してジャイロ尺度を校正した比較では、滑りの代表値が0付近または負にもなる。
しかし、同期を±5 ms変えるだけで数度変わるため、この比較だけでは滑りが小さいと判断できなかった。
その結果は[inferred_slip.png](inferred_slip.png)、`trial_metrics.csv`の接頭辞なし項目、[sensitivity.csv](sensitivity.csv)に残した。

## 同一動画内の向きから確認する

位置と向きを同じフレームで比較すれば、動画―ログの同期に依存せず目印中点の見かけの滑りを評価できる。
ただし赤・黄マーカーは高さが違い、カメラ真下位置も不明なので、画像上の線分角度をそのまま機体角にはしない。

床面への見かけの投影位置を`P_front`／`P_rear`、カメラ高さを`H`、マーカー高さを`h_front`／`h_rear`とすると、

```text
D = (1 - h_front/H) P_front - (1 - h_rear/H) P_rear
D + 一定の未知ベクトル = L [sin(psi), cos(psi)]
```

固定カメラ、剛体上の一定マーカー間距離、一定高さを仮定し、`D`の軌跡を円へ当てはめて未知の一定ベクトルを推定した。
マーカー間距離`L`は概測の50 mmへ固定せず、自由に推定した。
したがってこれは**幾何仮定に基づく姿勢の再構成**で、カメラ真下位置や車軸の独立測定ではない。
元の撮影プロファイルの「絶対位置・高さ補正済みyawは未検証」という位置付けは維持する。

円への当てはめ残差は概ね0.2～0.4 mm。
列正規化したヤコビアンの条件数は180度で約3、135度で約6、90度で約15～17、45度で約70～94。
短い円弧の45度は姿勢再構成が弱く、数値を確定値に使えない。
推定マーカー間距離も約53～60 mmとなり、概測50 mmとの差がある。
30 ms区間を交互に丸ごと除いた2通りの円推定と、微分窓変更の結果も各試行へ記録した。
条件数や区間除外の差は診断であり、独立な精度保証や信頼区間ではない。

## 姿勢による同期と横加速度

再構成した動画姿勢とジャイロ積分に対し、尺度・定数角度差・時刻差だけを合わせた。
位置軌跡、滑り角、終点誤差はこの時間合わせの目的関数へ使っていない。
既存の軌跡同期との差は6.4～14.1 ms。姿勢の当てはめRMSEは0.19～0.49度。
135／180度に限るジャイロ尺度は0.974～0.991で、姿勢のRMSEは0.26～0.43度だった。
45度には尺度が許容下限0.9へ達した例もあり、姿勢再構成の弱さを反映している。
これらはセンサーや投影誤差も含む実効的な整合値であり、独立なハードウェア同期ではない。

ログの`ego.horizon_accel.get`は、現ソースでは横軸IMUの20点平均。
2026-07-23の変更`fe76521`でモデル計算値から実測値へ変更されていることをGit履歴で確認した。
ただし実際の取得ELFとの同一性は確認できていない。
左正の記録を右正へ反転し、静止時のバイアスを除いた。
動画の2階微分を機体横方向へ投影し、`irq.period_us`中央値から計算した20点平均の遅れを加えて比較した。

姿勢同期後の42本で相関0.926～0.992、RMSE 0.35～0.96 m/s²。
尺度の診断値は0.981～1.045だったが、比較グラフ・RMSEを合わせるための尺度補正には使っていない。
IMU位置と目印位置の違いによる回転加速度、IMU取付角、重力成分、動画微分の雑音は残る。
波形整合は得られたが、これだけで車軸の滑り角が正しいとは言えない。

## 車軸からの位置ずれとの競合

目印中点の車軸からの前方距離を`l`、前進速度を`u`、角速度を`omega`とすると、
目印中点の横速度には回転による`l*omega`が含まれる。
車軸での横滑りが0でも、

```text
beta_marker = atan(l * omega / u)
```

となる。後方の点では旋回に対して遅れる。
滑りモデル`beta_dot=-beta/tau-omega`の準定常解`beta ≈ -tau*omega`と、
小角度・一定速度での`beta_marker ≈ l*omega/u`は、`l ≈ -u*tau`で同じ形になる。
今回のように速度が500だけのデータでは区別しにくい。

| 対象 | 滑りだけと仮定した時定数・3本中央値 | 位置ずれだけと仮定した前後距離・3本中央値 | 滑りモデルの残差・3本平均 | 位置ずれモデルの残差・3本平均 |
| --- | ---: | ---: | ---: | ---: |
| R180 | 10.99 ms | −5.47 mm | 1.58° | 1.59° |
| in R135 | 9.96 ms | −4.86 mm | 1.59° | 1.57° |

42本全体でも残差平均は滑りモデル1.59度、位置ずれモデル1.60度と近い。
これは**同じ観測に当てはめた残差の比較**であり、独立な試験での予測精度ではない。
滑りと位置ずれを同時に推定すると、条件数の中央値は約51、最大約223。
一部で滑り時定数が0下限へ寄り、位置ずれへ説明が移る。
目印位置を−5／−2.5／0／+2.5／+5 mmと仮定した場合の時定数と残差を、各試行の`offset_comparison.json`へ保存した。

したがって、「タイヤの滑りがない」とも「表の角度すべてがタイヤの滑り」とも結論できない。
モデル上の時定数や`-ay/beta`から求めた横力係数は目印位置に依存する診断値で、採用値にしない。

## 300／400／600候補への意味

前回のモデルは500の位置軌道に整合していても、時刻差・角速度尺度・目印位置を有効な滑り係数へ吸収できる。
今回、その混同が具体的に見えたため、前回の係数を物理的な滑り定数として別速度へ使う根拠は不足している。
作成済み候補は未確認の初期候補として保持し、自動更新や採用はしなかった。

次に優先するのは、追加走行より先に**赤・黄マーカーの位置と車軸中心の前後・左右位置差を測ること**。
これを既存動画へ適用すれば、位置ずれによる見かけの遅れを除いた再解析へ進められる。
その後、同じ機体・床・吸引条件の別速度で速度依存性を確認する。
