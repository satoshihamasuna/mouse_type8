## モデル

右位置`r`・前位置`f`はmm、右回り正の角度`psi`・進行方向の遅れ`beta`はrad、
速度`v`はm/s、角速度`omega`はrad/s、時刻はs。
右回りの符号はファームウェアと逆。

```text
dr/dt     = 1000 v sin(psi + beta)
df/dt     = 1000 v cos(psi + beta)
dpsi/dt   = omega
dv/dt     = (Gv vc - v) / tau_v          （停止指令前）
dv/dt     = -v / tau_brake              （停止指令後）
domega/dt = (Gw omega_c - omega) / tau_w
dbeta/dt  = -beta / tau_beta - omega
```

`tau_v`／`tau_w`は同定対象ログの指令と実測から推定。
`Gv`／`Gw`、500での`tau_beta`、停止時定数、実効的な時刻ずれを動画から推定した。
これらは制御応答・距離校正・同期・撮影誤差を含む有効値であり、物理定数ではない。
ログ分解能より短い時定数、0下限に達した横滑り時定数は精密な識別結果とは扱わない。
ヤコビアンを列正規化した条件数は全14種類で約6.4以下だったが、別速度の係数を識別できたことを意味しない。

指令は現ファームウェアの`accel_table[1001]`と`accel_Integral`を読み込み、
`omega_max=-1000*velo/r_min`、`T=abs(rad(degree+correction)/(accel_Integral*omega_max))`で生成する。
前後直進距離は`myshell.cpp`の単体試験に合わせた。
後走加減速度6.5 m/s²と停止直前の0.15 m/s下限、停止後の惰走を含む。
1 ms格子で一次応答と台形積分を行い、正確な停止時刻への補間で停止点の量子化段差を抑えた。
実測距離でのphase切替、初期横偏差による半径補正、壁制御は近似または省略している。

## 速度転用の仮定

500だけでは速度依存性を識別できないため、主候補には次を仮定した。

```text
tau_beta(v) = tau_beta(0.5) * (v / 0.5)^q
主候補 q=1、感度比較 q=-1 / 0 / 1
Gv, Gw, tau_v, tau_w, tau_brake, 時刻ずれは同一値を維持
```

主候補は、同じ半径での定常的な横滑り角が概ね速度の2乗で増える仮説に対応する。
この速度則を測定から確認したわけではない。
`q=-1`は同じ半径で横滑り角が概ね速度によらない仮説、`q=0`は時定数一定の仮説。
この3仮説以外の影響やゲインの速度依存、電圧・摩擦の影響までは範囲に含めていない。

500のモデルが出す終点を維持するよう、Lstart/Lendを解いた。
180度では終点だけで長さ2つを一意に分けられないため、前方頂点も維持し、半径・Lstart・Lendを同時に解いた。
500の元測定に残る目標からのずれを消す調整ではない。
数値的な終点・頂点の一致残差は最大0.0009 mmだが、これは最適化の内部整合であり予測精度ではない。
保存の0.001 mm刻みも推定精度を表していない。
論理角と角度補正は500の値を維持し、別速度での角度誤差は未確認。

## 検証結果と適用限界

各種類3本のうち1本を丸ごと除外して係数を同定し、除外した1本を予測する比較を全42通り行った。
予測器への入力はその試行の設定JSONと固定係数だけで、評価試行の指令CSV・実測速度・映像を予測入力にしていない。

- 500での全42比較の軌道RMSE平均：**1.88 mm**
- 各種類の軌道RMSE平均：**1.13～2.47 mm**
- 試行単位の軌道RMSE最大：**3.09 mm**
- 静止後終点の2次元誤差最大：**3.95 mm**
- 数値テスト5件：成功。符号・角度積分・左右対称・終点／頂点保持・速度則・停止を確認。
- Arm GNU C++14、Debug-MouseAのコンパイル定義・include・CPU設定で全42候補を構文検査：成功。

軌道RMSEは動作開始から動作終了+150 msまでの観測できたフレームの2次元距離誤差。
フレームごとの最大誤差は`validation.csv`の`path_max_mm`を参照する。
動画の全軌跡による時刻同期・初期直進による座標正規化は既存解析を利用しており、独立な盲検実験ではない。
`validation_500.png`の黒線は3本すべてで再同定したモデル、図題の値は試行除外交差検証の値。

主候補を固定して3種類の速度依存仮説で再予測すると、終点の500基準からのずれは
最大約4.26 mm（300のin R135）。135度系・V90はこの仮定の影響が比較的大きい。
これは不確かさ全体の上限や信頼区間ではない。
横滑りが0下限に達した種類で感度がほぼ0でも、その速度で精度が確認できた意味ではない。

600の半径30 mmの135度系では、指令上の最大横加速度は約12 m/s²となる。
同半径の500に対し約44%増えるので、500で飽和がなくても600の追従・滑りを保証できない。
元測定で指摘されていたin L135のばらつき、out L135の出口角の余裕不足も残る。

PID/FFは測定時の量子化済みRAM係数をそのまま保存した。
別速度でPID/FFを新しく同定したものではなく、現在の500のコンパイル済み精度とも差がある。
従来の300プリセットとはPID/FFが異なる。
400／600のプリセットやmode配列の追加、連続経路への接続、書き込み、走行は行っていない。
ファームウェアの有効なソースを変更していないためA/Bのリンクビルドは行っていない。

実機確認する場合は400で500近傍の転用を確認し、その後300／600を比較する。
各速度で動画＋実時刻ログを取得し、特に135度系・V90の終点と出口方向、飽和を評価してから採用する。
