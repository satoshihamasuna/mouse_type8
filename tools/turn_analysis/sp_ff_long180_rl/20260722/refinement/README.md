# Longturn180 SP-FF refinement

追加された現行FF適用済みログを使い、`current turn FF + SP feedback`を`alpha_mag`と`omega^2`へ再射影した。反復ログ数は1600 Rが3本、1600 Lが2本、2000 R/Lが各2本。

残差を一度に全量反映すると一部条件で`±1.0 V`クランプへ到達するため、反復学習ゲインを0.5として現行値から残差推定値へ半分だけ更新した。

| speed | direction | applied k_alpha | applied k_omega2 | projected voltage |
|---:|:---:|---:|---:|---:|
| 1600 | R | -0.00024186 | +0.00008612 | -0.283～+0.311 V |
| 1600 | L | -0.00023491 | +0.00010562 | -0.272～+0.307 V |
| 2000 | R | -0.00044945 | +0.00015873 | -0.762～+0.836 V |
| 2000 | L | -0.00043538 | +0.00013958 | -0.754～+0.821 V |

現行FFはFFなし／旧FFに対し、longturn180の速度誤差RMSを1600 Rで約27%、1600 Lで約27%、2000 Rで約26%低減した。2000 LはFFなしより改善したが、直前の共通係数試行より速度誤差RMSが約7%大きかったため、特に保守的な半更新とした。

今回の強い追加補正を同速度のlong90へ投影すると2000では約32%がクランプするため、更新対象は測定済みlongturn180だけとした。ほかの形状は前段のR/L方向別係数を維持している。
