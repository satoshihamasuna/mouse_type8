## 通信断試験の手順と証拠

1. Pythonから10秒録画を開始し、PC側サーバープロセスだけを停止。
2. Androidは録画を続け、時間指定でMP4を確定。
3. スマホ画面で「PCへ接続中」「未転送: 1件」を確認。
4. ADBのrun-asとtest -sで、対象MP4が端末内に実在し、空ではないことを確認（終了コード0）。
5. 同じ接続コードと保存先でPCサーバーを再起動。
6. Androidが自動再接続し、保留動画を転送。PixelCameraClient.wait_for_transfer(recording_id=...)がsource_deleted=Trueで完了。
7. 端末内の対象MP4にtest -eを実行し、存在しないことを確認（終了コード1）。

物理ケーブルを抜いた試験ではなく、PCサーバー停止による通信断の実機試験。USB抜き差しは別途検証が必要。
